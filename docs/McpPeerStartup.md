# MCP 의존성과 경량 RPC 클라이언트의 초기화

iimagent는 IPC 요청을 전달하는 클라이언트이며 Qt Core·Network에만 연결한다. 추론 서비스와 오디오·음성·ONNX 런타임은 데몬에서 사용한다. CLI가 추론 의존성의 전역 초기화를 함께 수행하던 연결을 분리하여 시작 비용을 줄인다. 인증 파일의 소유자·권한·크기 검사와 IPC 기한·프레임 제한은 그대로 유지한다.

관리된 SDK 가상 환경의 공식 MCP Python 의존성은 빌드 단계에서 표준 CPython 바이트코드를 준비한다. 원본 패키지를 수정하거나 실행하지 않으며, 인터프리터의 표준 캐시 무효화 규칙을 사용한다. 시스템 Python·SDK 바깥의 환경·외부 심볼릭 링크에는 기록하지 않는다. 기존 -B 실행 인자와 초기화 제한 시간은 유지한다.

`tests/mcp_bytecode_tests.py`는 준비 중 코드 비실행, 생성 결과의 실행 가능성, 소스 변경 후 갱신, 외부 경로 보존을 검사한다. 공식 stdio·HTTP 피어 테스트와 설치 소비자 검증은 별도로 실행한다.


## 순수 의존성의 표준 ZIP 가져오기

관리된 테스트 환경에서 순수 Python 패키지와 모듈을 표준 `zipimport` 아카이브로 준비하여 작은 파일의 반복 접근을 줄인다. 원본 파일과 설치 버전은 유지하며, 바이너리 확장이나 비정규 파일이 있는 패키지는 원래 파일 시스템에서 로드한다. 모듈의 바이트코드와 패키지 리소스를 함께 보존한다.

시작 시 인터프리터·최적화 모드, 원본 파일과 디렉터리의 정체성·크기·수정 시각 및 아카이브 SHA-256을 확인한다. 소스 수정·파일 추가·캐시 손상·형식 불일치 시 원래 로더로 복귀한다. 결과물은 관리된 환경 내부에만 기록하며, 인터프리터의 외부 캐시 경로 설정으로 쓰기 위치가 바뀌지 않는다. 테스트 명령, 공식 MCP 1.26.0 버전, 30초 초기화 및 60초 CTest 제한은 변경하지 않는다.

`tests/mcp_bytecode_tests.py`와 `tests/mcp_bundle_tests.py`를 `python3 -B`로 실행하면 출력 범위, 실제 코드·리소스 가져오기, 소스 변경·추가 시 복귀, 바이너리 확장·외부 링크 제외와 손상 검사를 수행한다. 이 캐시는 선택된 테스트 의존성 환경의 빌드 결과물이며 SDK 공개 API나 네이티브 애플리케이션 런타임의 의존성이 아니다.
