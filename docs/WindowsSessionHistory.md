# Windows 세션 기록 검사

세션 기록의 헤더·페이지·cursor 검증은 provider SourceAccess를 잡은 뒤 파일을 열고,
읽기 핸들을 닫은 뒤 잠금을 푼다. 비동기 미리보기의 NTFS 대체 스트림 게시가 읽기
중간에 들어와 파일 변경 토큰을 바꾸는 일을 막는다. 실제 외부 본문 변경, 같은 크기·
복원한 mtime의 변경, malformed record와 불완전 tail의 기존 검증은 유지한다.

세션 기록 검사에서는 예기치 않은 표준 예외의 원문을 Qt 실패 메시지에 보존한다.
미리보기 게시와 검색의 반복, cursor 무효화, Unicode excerpt, 구조화된 도구 필드와
원래 transcript 바이트 보존을 함께 검증한다.
새 검색의 회귀 검사는 16회 연속 본문 추가 직후, 미리보기 큐를 강제로 비우지 않고
같은 세션을 검색하여 모든 메시지가 순서대로 포함되는지 확인한다.
입력 큐·프로젝트 메모리·권한 갱신 검사는 build/에 원문 Qt 로그를 남긴다.
프로젝트 메모리·권한 검사 진입점은 예기치 않은 표준 예외의 원문도 stderr에 보존하여
Windows 크래시 요약만으로 실패 원인이 사라지지 않게 한다. 오류를 성공으로 바꾸지 않는다.
