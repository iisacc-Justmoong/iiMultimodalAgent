# macOS 통신 검사의 임시 경로

macOS의 Unix 소켓은 파일 경로 길이에 제한이 있다. 깊은 빌드 디렉터리에
소켓과 UUID 기반 임시 디렉터리를 함께 두면 `QLocalServer::listen: Name error`로
검사가 시작되지 않을 수 있다. Windows의 명명된 파이프와 경로 한도가 다르다.

통신 검사에서는 짧은 `TMPDIR`·`TMP`·`TEMP`와
`IILOCALLLM_APP_ENDPOINTS`를 사용하고, 상대 임시 경로를 만드는 검사의 작업 디렉터리도
같은 테스트 전용 위치로 맞춘다. 임시 파일은 저장소의 `build/` 아래에 둔다.
검사 보고서의 출력 경로는 통신 소켓의 임시 경로와 독립적으로 지정할 수 있다.
`project_memory_wire.py`는 `tempfile`의 설정된 임시 경로를 사용하므로
보고서가 깊은 디렉터리에 있어도 소켓 경로가 함께 길어지지 않는다.

이 설정은 호스트 검사의 파일 배치에 관한 것이다. 프로덕션 소켓 주소와 인증,
실제 추론의 완료 조건, 오류 단언은 변경하지 않는다. 통신 성공과 실제 모델의
도구 선택·문맥 한도·자원 수용 결과는 각각 확인해야 한다.

API 추론 픽스처의 모델 SHA-256 검사는 Python 3.9에서도 실행할 수 있도록
1 MiB 블록을 순차로 읽는다. Python 3.11부터 제공되는 `hashlib.file_digest`에
의존하지 않으며, 파일 크기·정확한 해시 검증과 파일 핸들의 종료를 유지한다.
